# 🌤️ Weather Dashboard Web App

A sleek, responsive weather application built with HTML5, CSS3, and JavaScript that provides real-time weather forecasts, temperature trends, and atmospheric details for any location worldwide.

---

## 🚀 Live Demo

Check out: https://realtime-weatherwebapp.netlify.app/

---

## ✨ Features

* **Real-Time Weather Data:** Search for any city to instantly view current temperatures, humidity, wind speed, and atmospheric pressure.
* **5-Day Forecast:** Plan ahead with reliable multi-day weather predictions.
* **Dynamic Backgrounds:** UI accents and background visuals change dynamically based on weather conditions (Sunny, Rainy, Snowy, Cloudy).
* **Responsive Design:** Optimized for mobile phones, tablets, and desktop viewports.

---

## 🛠️ Built With

* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript
* **API:** [https://api.open-meteo.com]
* **Icons:** FontAwesome / Lucide Icons
