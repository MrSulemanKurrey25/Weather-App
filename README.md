# 🌤️ Weather Dashboard Web App

A sleek, responsive weather application built with vanilla JavaScript, HTML5, and CSS3 that provides real-time weather forecasts, temperature trends, and atmospheric details for any location worldwide.

## ✨ Features

* **Real-Time Weather Data:** Search for any city to instantly view current temperatures, humidity, wind speed, and atmospheric pressure.
* **5-Day Forecast:** Plan ahead with reliable multi-day weather predictions.
* **Dynamic Backgrounds:** UI accents and background visuals change dynamically based on weather conditions (Sunny, Rainy, Snowy, Cloudy).
* **Responsive Design:** Optimized for mobile phones, tablets, and desktop viewports.
* **Geolocation Support:** Automatically detects your current location to fetch local weather data (optional permission required).

---

## 🛠️ Built With

* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)
* **API:** [OpenWeatherMap API](https://openweathermap.org/) (or specify your API provider)
* **Icons:** FontAwesome / Lucide Icons
